The one idea to remember

Ice charts tell a captain what the ice looked like when the satellite passed. A ship takes four to ten days to cross the pack. This project asks a different question: what will the ice be like at each point when the ship actually gets there? It answers that with a corrected forecast, plans the route against it, and then refuses to call the route safe for anything it has no evidence on.

That last part matters as much as the forecast. The capability, traffic, communications and execution gates show UNKNOWN because the data that would settle them (the ship's certificate, a live AIS feed, a link budget, bridge sensors) is not held. The chart gate can never pass, because the seabed data is a scientific compilation, not an official chart. Weather is assessed from real waves and wind but never claims to have checked visibility. The system says all of this out loud instead of showing nine green lights.
